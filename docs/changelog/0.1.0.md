# qwen-asr v0.1.0

Date: 2026-11-12

首个版本: 通过本机已有的 llama.cpp 运行 Qwen3-ASR 的本地转录命令行工具.

## Highlights

- 本地离线转录, 音频不上传; 使用本机已有的 llama.cpp 动态库, 缺失时提示安装.
- 首次运行时引导下载模型, 有 `modelscope` / `hf` 就复用, 没有则用内置并发下载器.
- 一次转录可同时输出 txt, srt 与 json, 支持整目录批量处理.

## Features

- **CLI**: 默认命令直接转录, 支持文件与目录输入, `-j` 控制分段并发, `--chunk-seconds` 控制单段上限.
- **模型管理**: `models list` / `models path` / `models download` 三个子命令, 提供 `0.6b` 与 `1.7b` 两档 Q8_0 量化模型.
- **引擎解析**: 显式目录优先, 否则检测系统安装并实际加载符号; 没有可用引擎时直接报错, 不内置或自动下载 llama.cpp.
- **音频处理**: wav / mp3 / flac 由内置解码器处理, 不依赖 ffmpeg; 检测到 ffmpeg 时额外支持 mp4 / mkv / m4a 等容器.
- **分段**: 按能量检测静音, 优先在静音处切分, 没有静音时按上限硬切, 保证每段不超过模型可处理长度.
- **输出**: srt 使用分段边界作为时间戳; json 含每段起止时间与文本.
- **诊断**: `doctor` 子命令报告引擎来源, ffmpeg 可用性与模型就绪情况.

## Upgrade Notes

1. 运行前请安装支持 Qwen3-ASR 且包含 mtmd 的 llama.cpp 共享库, 并用 `doctor --engine-only` 验证.
2. 首次运行需要下载模型 (0.6b 约 1.0 GB, 1.7b 约 2.5 GB), 内网环境可先手动执行 `models download`.
3. 不安装 ffmpeg 时无法直接处理视频文件, 请先提取音轨为 wav 或 mp3.
